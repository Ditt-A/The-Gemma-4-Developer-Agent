Variasi contract-first memaksa kebutuhan issue menjadi daftar perilaku yang dapat diperiksa: nama API, signature, pesan error, exception, default, status code, kompatibilitas dan edge case. Ini membantu menghindari patch yang terlihat masuk akal tetapi berbeda dari kontrak tes. Bounded Rescue memberi jalur pencarian graf yang sangat terbatas ketika pencarian teks gagal. Penerapannya berbeda dari banyak resep yang melarang graph tools sepenuhnya. Efektivitas masing-masing pilihan tetap perlu diuji dengan harness dan task yang sama. [Contract-first](https://www.kaggle.com/code/nilanjansaha123/gemma-4-dev-agent-contract-first-1-agent-bundle?scriptVersionId=357147785), [Bounded Rescue](https://www.kaggle.com/code/lynnsakurai/gemma-4-budget-fit-agent-w-bounded-rescue?scriptVersionId=358320692).

Beberapa instruksi peserta sudah berbeda dari dokumentasi harness saat ini. README resmi yang diunduh menyatakan perubahan pada file tes dan konfigurasi terlindungi akan dibuang dari patch, sehingga klaim prompt bahwa setiap edit tes otomatis menggagalkan seluruh task terlalu luas. Bandingkan task yang benar-benar terselesaikan, empty patch, invalid tool calls, latency dan total runtime. Ulangi kontrol jika memakai public submission karena satu draw belum mengukur efek metode.
